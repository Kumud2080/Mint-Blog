# Mint Blog

A full-stack CRUD blog application built with Node.js and Express.js. Users can create, edit, and delete blog posts through a clean, responsive web interface.

## Features
- Create, read, update, and delete blog posts
- Server-side rendering with EJS templating
- RESTful routing for content handling and navigation
- Responsive UI with CSS
- Deployed on Render

## Tech Stack
Node.js · Express.js · EJS · CSS · JavaScript

## Getting Started

1. Clone the repository
```bash
   git clone https://github.com/Kumud2080/Mint-Blog.git
   cd Mint-Blog
```

2. Install dependencies
```bash
   npm install
```

3. Run the app
```bash
   npx nodemon index.js
```

4. Open `http://localhost:3000` in your browser
