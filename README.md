# Mint Blog

A full-stack CRUD blog application built with Node.js and Express.js. 
Users can create, edit, and delete blog posts through a clean, 
responsive web interface.

## Features
- Create, read, update, and delete blog posts
- Server-side rendering with EJS templating
- Responsive UI with CSS
- Deployed on Render

## Tech Stack
Node.js · Express.js · EJS · CSS · JavaScript
